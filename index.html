Log daily claims

Enter the day's total. Saving replaces any number already logged for that date, so you can also use this to correct an entry.

Leave, holiday, or absence?

For planned or vacation leave, type VL in the Claims cell of the sheet. For a client holiday, type CH. Both are left out of Avg Claims / Day, so they won't count against you.

Leave a day blank only if it hasn't been logged yet. Blank work days show up as missing.

Use Mark as absent (ABS) only for an unplanned absence. It logs a 0, which does count toward the average.
